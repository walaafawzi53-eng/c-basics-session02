# C# Assignment Project

This is a .NET 8 Console Application containing solutions for Q01–Q10 from the supplied C# Assignment sheet.

## How to open in Visual Studio
1. Extract `CSharp_Assignment_Project.zip`.
2. Open the `CSharp_Assignment_Project` folder.
3. Double-click `CSharpAssignment.csproj` (or use **File > Open > Project/Solution** in Visual Studio).
4. If Visual Studio asks to install a .NET 8 SDK, install it.
5. Press **Ctrl + F5** to run without debugging.

## How to run from a terminal
Open a terminal in this folder and run:

```bash
dotnet run
```

## Files
- `CSharpAssignment.csproj` — project configuration.
- `Program.cs` — Book class and answers to Q01–Q10.

The code is organized with question labels so each answer is easy to find.
